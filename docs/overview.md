# 社内問い合わせチケット管理システム

## 1. 目的

社内の問い合わせを **Redmine** のチケットとして管理し、営業担当者とサポート/技術担当者のやり取りをフロントエンドから簡単に行えるようにします。主な要件は次の通りです。

- 営業担当者が問い合わせを作成し、対応結果・再質問を追跡できる。
- サポート/技術担当者が回答コメントを追加し、ステータスを更新できる。
- Redmine のワークフローを活用しつつ、利用者は専用 UI を通じて操作する。

## 2. 主な構成

```
[Browser]
   |
   | HTTP
   v
[Frontend] (React/TS)
   |
   | REST API
   v
[Backend API] (FastAPI/Python)
   |
   | Redmine REST API
   v
[Redmine] (6.1.x)
   |
   | PostgreSQL
```

- **Frontend** – 営業・回答者向けの UI。Vite + React/TypeScript。
- **Backend API** – FastAPI で構築。Redmine API をラップしてフロントエンドと連携。
- **Redmine** – チケット・コメント・ステータス・ワークフロー管理。
- **PostgreSQL** – Redmine のデータベース。

## 3. 主要なユースケース

| 役割 | 典型的な操作 |
|------|--------------|
| 営業担当者 | 問い合わせチケット作成 → 対応確認 → 再質問またはクローズ |
| サポート/技術担当者 | チケット確認 → コメント追加 → ステータス更新 |

詳細はそれぞれのドキュメントで解説します。
