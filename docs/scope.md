# MVP スコープ

## 実装範囲（含む）

1. 営業担当者が問い合わせチケットを作成。
2. 回答者が未回答・回答待ちのチケット一覧を確認。
3. 回答者がチケットに回答コメントを追加。
4. 回答者がステータスを変更し営業へ戻す。
5. 営業が回答を確認。
6. 営業が再質問コメントを追加し、チケットを「対応待ち」に戻す。
7. 回答者が再質問に対応する。
8. 営業が納得したらチケットをクローズ。
9. すべての履歴を監査ログで確認。
10. チケットの優先度を Redmine の設定値から選択・変更。
11. 問い合わせ、報告書、客先同行のいずれか1つを選択してチケットを作成。
12. 報告書と客先同行の両方が必要な場合は、それぞれ別チケットで管理。
13. 報告書では報告書渡し済み、客先同行では予定・担当者アサイン済みをサポート担当者が更新。
14. 回答者向け一覧で現在の担当者と前回のサポート対応者を確認。
15. 客先同行の作成時にオンラインまたはオフラインを必須選択し、作成後はサポート担当者だけが変更。

## 実装除外（後日検討）

- LLM による問い合わせ分類・回答生成・要約
- 添付ファイルアップロード
- メール・Teams/Slack 通知
- 複数 Redmine インスタンス対応
- HTTPS 終端
- OIDC / LDAP 認証連携

## 期待成果

- 営業が簡単に問い合わせを行える UI。
- サポート/技術担当者が迅速に回答できる API。
- Redmine での完全な監査ログ。
