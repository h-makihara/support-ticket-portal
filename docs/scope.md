# MVP スコープ

## 実装範囲（含む）

1. 営業担当者が問い合わせチケットを作成。
2. 回答者が未回答・回答待ちのチケット一覧を確認。
3. 回答者がチケットに回答コメントを追加。
4. 回答者がステータスを変更し営業へ戻す。
5. 営業が回答を確認。
6. 営業が追加質問コメントを追加。
7. 回答者が追加質問に回答。
8. 営業が納得したらチケットをクローズ。
9. すべての履歴を監査ログで確認。

## 実装除外（後日検討）

- LLM による問い合わせ分類・回答生成・要約
- 添付ファイルアップロード
- メール・Teams/Slack 通知
- 複数 Redmine インスタンス対応
- HTTPS 終端
- OIDC / LDAP 認証連携

## 期待成果

- 営業が簡単に問い合わせを行える UI。
- サポート/技術担当者が迅速に回答できる API。
- Redmine での完全な監査ログ。
